# README screenshot

`botter-terminal.jpg` presents the complete actual output of `botter --help`
from Botter 0.8.1-next.0 in a decorative terminal frame. The frame is original
documentation artwork; it adds no product interface and contains no account data.

The command runs offline. Refresh the image when top-level help changes, preserving
its complete output. Do not substitute fictional successful API responses. The
image ships with the installed package as part of its documentation.

This asset is covered by the repository MIT license. Its layout follows Dotter;
OpenCode inspired the README structure, with no reused third-party artwork.
